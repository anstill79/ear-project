What is this test, in plain terms?

SAL (Sensorineural Acuity Level) is a workaround for a specific problem: sometimes you can't mask an ear properly with the usual method because any masking noise loud enough to reach the test ear is also loud enough to cross over into the ear you're trying to mask — a "masking dilemma." Instead of masking in the ear, SAL puts noise on the forehead via the bone oscillator. If the ear has a conductive component, that noise gets blocked from reaching the cochlea (just like an air-conduction sound would be), so the air-conduction threshold gets worse with the noise on. If the loss is purely sensorineural, the noise reaches the cochlea just fine and barely changes the threshold. That difference is used to estimate the true bone-conduction threshold.

When should I use it?

Use SAL when a patient has (or is suspected to have) a conductive loss in both ears with large air-bone gaps — the classic case where regular masking would overmask and you can never get a stable, cross-checked threshold.

Step-by-step: how to run the test

  1. Get an unmasked air-conduction (AC) threshold at 500 Hz, 1000 Hz, 2000 Hz, and 4000 Hz in each ear, the normal way (headphones/inserts, no masking noise). Enter these in the "Initial AC" row for the matching ear.
  2. Move the masking noise to the forehead. Place the bone oscillator at the center of the forehead and route narrow-band noise (NBN) to it through your audiometer's second channel.
  3. Turn the forehead noise up to the reference level for that frequency. This is the maximum noise output your audiometer can deliver through the bone oscillator at that frequency — use the default reference levels built into this app, or your own measured norms (see below).
  4. Re-test the same AC thresholds, at the same four frequencies, in the same ear, with the forehead noise still playing. Enter these new thresholds in the "Masked AC" row.
  5. Repeat steps 1–4 for the other ear. As you type, the "Est. SAL BC" row and the chart below fill in automatically — you don't calculate anything by hand.

How do I read the chart?

For each ear and frequency, the chart shows three markers connected by lines:

  • Initial AC (open circle for right, "X" for left) — your first, unmasked air-conduction threshold.
  • Masked AC (same shape, connected to Initial AC by a solid curved line) — the threshold after adding forehead noise. If this is much worse than the Initial AC, that's a sign of conductive loss.
  • Est. SAL BC (bracket symbol, the standard audiogram symbol for masked bone conduction) — the estimated true bone-conduction threshold, calculated from how much the noise shifted the AC threshold.
  • A thin dashed line (toggle it with the checkbox above the chart) connects the Initial AC symbol straight down/up to the Est. SAL BC bracket, so you can see at a glance how close — or how far — the estimated bone score landed from where you started.

Hover over any "Est. SAL BC" result to see warnings if a value looks off (for example, if the masked threshold came back better than the unmasked one, which shouldn't normally happen).

Why does the calculation work this way?

Each audiometer has a different maximum output for bone-conduction narrow-band noise at each frequency (usually 40–60 dB). Manufacturers and researchers have measured, in people with normal hearing, how much a threshold typically shifts when that maximum noise is applied at the forehead — that's the "Norm Shift" value in the table. If your patient's actual shift (Masked AC minus Initial AC) is close to that normal shift, it suggests little or no conductive component. If the shift is smaller than normal, it suggests a conductive loss, and the app estimates the bone-conduction threshold as: Norm Shift − (Masked AC − Initial AC), subtracted from the normative value, and displayed as the "Est. SAL BC" result.

Should I use the built-in norms or my own?

The default "Norm Shift" values are reasonable starting points, but every audiometer/transducer/booth combination is a little different. For the most accurate results, measure your own norms (below) and load them with the Custom Norms button.

How do I create my own norms?

Test air-conduction on a few normal-hearing subjects at 500Hz, 1kHz, 2kHz, and 4kHz in each ear (unilateral is also fine). Retest the same subjects at the same frequencies via AC, but with the bone oscillator on the forehead and channel 2 routed to bone conduction with NBN signal at the highest output the machine allows. Subtract the unmasked threshold from the masked threshold to get the shift value for each frequency. Average the shift values across your subjects to get the norm value for that frequency.

How do I save my norms?

Click the Custom Norms button, enter your data, and click Save. The norms are saved only on the computer you're currently using — this app does not send or sync any data remotely.

What if I run out of equipment headroom before I get a masked response?

This can happen with mixed losses where the true bone-conduction threshold is already in the moderate range. Try a different AC transducer to see if it has more output. If that doesn't help, you may need to report the result as "masking dilemma" rather than a specific threshold.
